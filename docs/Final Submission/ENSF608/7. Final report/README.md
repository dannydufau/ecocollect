# Final report

[EcoCollect_ENSF608_Final_Report_Group9.pdf](EcoCollect_ENSF608_Final_Report_Group9.pdf) is the ENSF 608 report. `main.tex` is its source. The other `.tex` files, `sql/` and `figures/` are included by it, and `figures/source/` holds the editable draw.io diagrams.

This repository is public, so the cover of this copy lists team members' names only.

To rebuild from this folder with [Tectonic](https://tectonic-typesetting.github.io/):

```bash
tectonic main.tex
```
